# Nolyth AI Bootcamp - Sprint 02: Data Analysis & Machine Learning

This repository documents my progress through **Sprint 02** of the Nolyth AI Bootcamp (Associate AI Engineer Training Program). The sprint focuses on turning raw datasets into insights and beginner machine learning models — NumPy, Pandas, EDA, visualization, model training, and evaluation.

## Program Info

**Program:** Nolyth AI Bootcamp - Associate AI Engineer Training
**Sprint:** 02 - Data Analysis & Machine Learning
**Duration:** 2 Weeks (Days 1-14)
**Stack:** Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter/Colab

## Sprint Project

**Customer Churn Prediction** — a full data science workflow covering data cleaning, exploratory data analysis, visualization, and machine learning classification, built on the [Telco Customer Churn dataset](https://www.kaggle.com/) and following the Sprint 02 stack end-to-end.

## What This Repo Covers

| Area | What to Learn / Practice | Expected Output |
|---|---|---|
| Data Analysis Tools | NumPy arrays, numerical operations, Pandas Series/DataFrames, CSV loading, data inspection | Dataset loaded with basic checks and notes |
| Data Cleaning | Missing values, duplicates, type conversion, filtering, grouping, feature creation | Cleaned dataset with documented preprocessing |
| EDA + Visualization | Patterns, trends, outliers, correlations; bar charts, histograms, scatter plots, heatmaps | EDA report with charts and written insights |
| ML Basics | Regression, classification, clustering, train/test split, baseline models, overfitting | Baseline model with clear target and features |

| Polish + Demo | Clean code, final visuals, README, explanation, limitations, next steps | Final project submission package |

## Minimum Functional Requirements

- Dataset loading and clear problem statement
- Data cleaning and preprocessing steps
- EDA with at least 4 meaningful charts
- Written insights, not only visual outputs
- At least 2 ML models or baseline comparison
- Train/test split and evaluation metrics
- GitHub repository with README, setup steps, and screenshots
- Short demo explaining dataset, approach, results, and limitations
